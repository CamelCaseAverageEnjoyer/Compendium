> Проект по кандидатской диссертации. Групповой полёт КА типа PCBsat, определение их углового и поступательного движения.

<u>Сценарии</u> запускаются функцией `main`, там же документация по сценариям. <br>
Во всех сценариях траектории всех CubeSat, PCBsat интегрируются в ИСК в полной модели движения.
